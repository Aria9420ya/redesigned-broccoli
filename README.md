# COF Electrospun PEM Research System

This repository is a long-term knowledge base and workflow system for covalent organic framework (COF) based electrospun proton exchange membranes (PEMs) for PEM fuel cells.

## Research Aim

Build a mechanism-driven research system that connects:

COF chemistry -> electrospun membrane architecture -> proton transport -> membrane stability -> MEA fuel-cell performance.

## Start Here

Open [`research_system/START_HERE.md`](research_system/START_HERE.md) for the full workflow.

## How To Work With Codex

Ask Codex to use the COF PEM research skill, then name the task:

- Literature: "用 COF PEM research skill，整理这篇论文并更新文献矩阵。"
- Experiment: "根据知识库设计下一轮 COF/PFSA 静电纺丝膜实验。"
- Analysis: "解释这组 EIS、吸水率、溶胀和拉伸数据。"
- Writing: "根据当前知识体系生成论文图谱和 introduction 大纲。"
- GitHub: "把今天的研究进展提交，并创建下一步 issues。"

## Context Rule

Keep durable memory in files, not in chat. Chat should hold only the current question and a short working summary.
